Асинхронный B2B SaaS-микросервис для профессионального мониторинга конкурентов на маркетплейсе **Ozon**.
Сервис осуществляет автоматический трекинг розничных цен, цен по **Ozon Карте**, себестоимости, расчет темпов продаж (Stock Velocity) и оценку выручки конкурентов с изолированным управлением через Telegram-бота.

---

## Ключевой функционал

- **Обход WAF и антифрод-защиты Ozon (Kasada / Fabio Challenge):** пул долгоживущего Chromium на базе Playwright с блокировкой тяжелых медиаресурсов (потребление RAM ~70 МБ).
- **Раздельный учет цен:** мониторинг обычной цены, субсидированной зеленой цены по Ozon Карте и старой зачеркнутой цены до скидок.
- **Бизнес-разведка продаж (Stock Velocity):** фиксация изменения остатков на складах конкурентов с автоматическим расчетом проданных штук и расчетного объема выручки.
- **Контроль себестоимости (Target Price):** экстренные алерты при падении цены конкурента ниже минимально допустимого порога селлера в рублях.
- **Многопользовательская изоляция (Multi-tenancy):** независимые рабочие пространства селлеров на базе `telegram_chat_id` с составными уникальными индексами.
- **B2B-командный доступ:** подключение рабочего группового чата команды селлера через команду `/connect` для оперативного реагирования сотрудников.
- **Аналитические отчеты Excel (.xlsx):** генерация таблиц с автоподбором ширины столбцов, закрепленной шапкой и интерактивными автофильтрами сортировки.
- **Административная панель (`/admin`):** сбор сводных коммерческих метрик, управление тарифными лимитами пользователей, экспорт резервных копий БД и массовые рассылки (`/broadcast`).

## Архитектура сервиса

Проект спроектирован по принципам слоистой архитектуры (Clean Architecture / SoC):
```text
ozon_tracker/
├── alerts/ # Telegram-интерфейс на aiogram 3.x (хендлеры, транспорт алертов)
├── config/ # Конфигурация через pydantic-settings
├── database/ # Модели SQLAlchemy 2.0 Async, сессии aiosqlite, репозиторий
├── parsers/ # Пул браузера Playwright, stealth-обход и каскадный парсинг
├── schemas/ # Типизированные DTO-контракты на базе Pydantic v2
├── services/ # Финансовая математика демпинга, расчет выручки и оркестрация
├── docker-compose.yml
├── Dockerfile
├── main.py # Точка входа, жизненный цикл браузера и планировщик задач
└── requirements.txt
```
